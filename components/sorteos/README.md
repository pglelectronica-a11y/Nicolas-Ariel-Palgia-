# `components/sorteos/`

Reservado para los componentes propios del módulo de negocio Sorteos: grilla de números (construida siempre a partir del número inicial y la cantidad configurados en cada sorteo, nunca de un rango fijo — Sprint 4, sección 3.5), tarjeta de premio, contador regresivo.

Se construye en el **Módulo 3 — Participación del usuario**. A diferencia de `components/ui/`, estos componentes sí conocen el negocio de sorteos.
