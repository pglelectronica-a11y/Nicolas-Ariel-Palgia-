# `components/peggie/`

Reservado para el avatar, la burbuja de mensaje y la lógica de variantes de frases de Peggie (docs/SPRINT-1-FUNCIONAL.md, sección 8.6, y SPRINT-3-DISEÑO-VISUAL.md).

Se construye en el **Módulo 3 — Participación del usuario**, junto con las pantallas donde Peggie aparece. Peggie nunca se monta del lado del administrador (`app/(administrador)/`).
